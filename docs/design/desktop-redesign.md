# UnoSkills 桌面界面重设计

这份提案覆盖主窗口、技能库、技能组合、发现和设置。以 1240 × 780 的运行截图、960 × 600 市场截图及现有代码为依据。相邻的 [交互原型](desktop-redesign-preview.html) 使用样例数据。尺寸均为默认 14 px 字号下的逻辑像素。

## 现状与取舍

| 现场看到的问题 | 改动 | 用户能做什么 |
| --- | --- | --- |
| 默认窗口侧栏约 254 px，技能库另有 330 px 列表，四页入口也各用一套页头 | 共用 184 px 侧栏、页头及内容对齐线。窄窗切到 56 px 图标栏 | 转页时从固定位置找到导航和操作，更多宽度留给技能名与正文 |
| 技能库把 Agent 开关平铺到检查器。作用范围和危险操作分散 | 列表显示当前范围的部署覆盖。检查器把范围、Agent 和结果放到同一区域 | 看清这份技能装到了哪里，决定操作全局还是某个项目 |
| 市场同时出现两层相似的分段控件，卡片反复展示「安装」和外链 | 子页用下划线 Tab，榜单用排序选择。选中卡片后在详情面板提供安装 | 先扫描和比较来源，再确认安装对象 |
| 组合页同时展示创建和粘贴 TOML。详情同时摆放整组和逐项安装 | 组合页先阅读与比较，创建和导入使用独立工作区。详情汇总差异后再确认 | 看清组合内容、已有技能和将新增的技能 |
| 收编页以「全部收编」作主按钮。设置标题介绍注册表，首页却混排语言、部署、主题和字体 | 收编按 Agent 分组，数量由勾选结果决定。设置分区按任务命名，使用单列设置行 | 在明确范围内批量处理。按目标找到设置并读完长描述 |

## 窗口与导航

- **标题栏 36**。左侧放 UnoSkills 标记和产品名。过程消息使用固定插槽。检测到新版本后显示更新入口，打开「关于与更新」。语言、主题、扫描各归到对应页面。
- **侧栏 184 / 56**。顶部依次放「技能库」「技能组合」「发现」，底部放 Agent 状态和「设置」。边距 8，条目高 36、间距 4、图标 16，标题文字 14。窗口宽度小于 1080 时收成图标栏。图标提供工具提示与无障碍名称。手动折叠可记忆。
- **页头 56**。四页标题起点、底边和操作位一致。内容水平边距 20。页头右侧放当前页面动作，例如「从链接安装」「新建组合」「添加 Agent」。说明和状态出现在做决定的位置。
- **页内 Tab 36**。切换独立内容用下划线 Tab，左对齐。市场、收编属于发现页，推荐、我的组合属于组合页，预览、部署属于技能检查器。分段控件用于「浅色 / 深色」一类的值。排序、部署范围和字体用选择器。当前对象的更新、定位、复制和删除进入溢出菜单，删除单独分隔。
- **工具栏 48**。左侧先搜索，再是筛选和排序。搜索默认宽 280，缩到 160 后优先换行。已加载数量和当前范围放在列表标头或底部。页头与工具栏常驻，分栏场景里列表与检查器各自滚动。
- **宽度策略**。1240 与 1440 优先展示并列检查器。列表和检查器并排至少需要 360 + 416 px，技能组合索引例外，最低 264 px。当可用空间不足时使用带返回位的详情视图或 380–416 px 侧面板，保留选中项与滚动锚点。960 × 600 是最小窗口验收尺寸。

## 技能库

**流程**　查技能 → 看全局或项目范围 → 看部署覆盖 → 选择目标或打开文件预览。

| 区域 | 排版与组件 | 交互 |
| --- | --- | --- |
| 页头 | 「技能库」与「安装技能」 | 安装打开来源输入。成功后选中新技能，并在详情标示「已加入技能库」 |
| 工具栏 | 搜索、范围选择、Agent 筛选。标头为「技能」「部署」「估算 tokens」 | 匹配名称、标签和描述。切范围后用对应记录计算覆盖。清除搜索保留范围 |
| 列表 | 48 px 虚拟列表行。技能名 14，来源 12。覆盖率与 token 右对齐。选中行用主题色浅底与细轮廓 | 鼠标与方向键同步选中检查器。Enter 打开详情。右键与详情右上的菜单命令一致。列空间不足时把 token 移入详情 |
| 检查器页头 | 名称 20，来源和估算 tokens 为次级信息，路径收在「打开目录」旁 | 路径可复制，更新检查、定位与移除进入菜单。长名截断时悬停显示完整名称 |
| 部署 | 默认展示。明确写「全局」或项目名。Agent 用 36 px 状态行，显示「已部署」「可部署」「冲突」「未检测」 | 每次更改的目标明确可见。提交期间停用该目标控制。实际成功后更新覆盖与通知。冲突显示路径和处理入口 |
| 预览与编辑 | 「预览」显示 SKILL.md 正文，另设「编辑」动作。正文字号 14、行高 22，阅读宽度约 70 个拉丁字符 | 编辑栏固定「保存」「取消」。退出有改动的内容时提示保存或放弃。长文警告放在正文或 token 附近，并本地化 |

空库提供「安装技能」和「收编本机技能」。搜索为空保留筛选条件和清除入口。尚无部署时保持范围和各 Agent 的可用状态。配置了很多 Agent 时通过过滤或检查器浏览。

## 技能组合

- 页内 Tab 为「推荐」「我的组合」。页头有「新建组合」「导入 TOML」。复制 TOML、分享 Gist 和删除归到选中组合的菜单。
- 两个 Tab 共用「索引 + 详情」。索引默认宽 304，行高 60，显示组合名、技能数、一行用途。标签用筛选菜单收纳。详情按组合名与说明、技能清单、确认操作布置。
- 技能清单用 40 px 行展示名称、来源和「已在库中」「待新增」「冲突」。确认时显示实际新增数、已有数及冲突项。只入库的提交使用「加入技能库」。需要部署时进入带目标选择的步骤。
- 新建使用单列编辑页。先填名称和用途，再搜索并勾选技能。底部固定「保存组合」。导入打开约 520 px 面板，粘贴或选取 TOML，预览解析结果后提交。修正字段错误时保留已填写内容。
- 安装部分失败后显示已加入和失败项的计数与原因，可重试失败项。分享由用户实际触发。

## 发现

### 市场

- 页头「发现」右侧放「从链接安装」，页内 Tab 为「市场」「收编」。工具栏依次为搜索、榜单选择、来源筛选、刷新。默认热门趋势。搜索提交后显示「搜索结果」并隐藏排名。清空搜索返回先前榜单与滚动位置。来源筛选明确写「已加载结果」，顶部显示可移除的筛选条件。
- 卡片高 76，间距 12，标题 14 px，来源与安装量 12 px。两行依次放名次与名称、来源与安装量。名次用统一窄位，榜首用主题色轮廓。官方标记在宽度不足时折叠为有名称的状态图标。已入库状态在卡片可见。简介由外部详情页提供，市场列表直接使用榜单数据。
- 列数按网格实际空间计算。宽度 ≥ 816 px 三列，540–815 px 两列，更窄一列。由 264 px 最小卡宽与 12 px 列间隙得出。默认窗口与自动折叠侧栏后的 960 px 窗口都能排三列。最后一行保持同列宽，切列时以技能 ID 保持滚动位置。
- 单击或 Enter 打开 380–416 px 详情，显示技能名、完整来源、安装量和本地状态。底部明确「加入技能库」，次级动作是「在 skills.sh 查看」。收到安装结果后保持位置，更新动作成「查看技能」。
- 缓存命中时整组替换榜单。首次加载占位保持网格尺寸。刷新期间旧结果继续可用，错误提示放在筛选条附近。分页失败在列表尾提供重试。

### 收编本机技能

- 搜索匹配名称、Agent 或路径。按 Agent 分组，用 32 px 折叠组头和 40 px 候选行。行内显示勾选、名称、路径尾部、估算 tokens、冲突状态。
- 组头显示候选数，提供明确范围的「选中此组」。顶部提供「重新扫描」。选中后底部固定「已选择 N 项」和「收编 N 项」。确认交代写入库的动作、范围及冲突数。
- 收编后以实际结果更新数量，失败项留在列表供重试。折叠组移出键盘焦点顺序，把焦点交回组头。空态区分「没有未收编技能」和「筛选无匹配」。

## 设置

- 布局为「设置分区 → 单列设置流」。宽屏分区导航宽 156，表单流最大 680。窄屏用当前分区的选择器。每行至少 56，左侧标签和说明，右侧控制，说明过长时控制移到下一行。每组用分隔线划分。
- **通用**　语言、默认部署方式、技能库目录。部署方式的说明交代实际生效范围。路径操作使用「打开目录」。
- **外观**　主题、字号、UI 字体、等宽字体、主题预设与圆角。展示实际使用的字体名称，字号与主题更改就地预览。
- **网络与备份**　代理和 Git 备份分组。凭据使用安全控件，修改在明确提交时应用。用户发起连接测试后，成功、失败和重试保留在操作下方。
- **Agent**　默认展开「已检测」，折叠「未检测」。按「Agent」「技能目录」「启用」对齐。扫描结果和启用是独立状态。「添加 Agent」使用只含名称和目录的短表单。截断路径可查看完整值。
- **关于与更新**　版本、检查更新、验证和更新安装。标题栏更新入口直达此分区。安装与重启由用户触发。

## 视觉系统与交互尺寸

| 用途 | 深色预览 | 浅色预览 | 原生取值 |
| --- | --- | --- | --- |
| 主内容 | #14171D | #FCFCFD | theme.background |
| 侧栏与工具区 | #181C23 | #F3F5F9 | theme.sidebar 或同级表面 |
| 检查器与浮层 | #1D222C | #FFFFFF | theme.group_box / theme.popover |
| 正文 | #E8EDF5 | #182232 | theme.foreground |
| 次级文本 | #A9B3C4 | #526071 | theme.muted_foreground |
| 分隔线 | #343D4E | #DCE2EB | theme.border |
| 主操作与文字 | #A6BCFF / #14223E | #315AC5 / #FFFFFF | theme.primary / theme.primary_foreground |

主题色负责聚焦、选择和表单确认。绿色负责成功或已部署，琥珀色负责冲突和预算提示。原型值是主题预案，原生组件从主题取值。状态带文本或可读图标名。正文目标对比度 ≥ 4.5 比 1，焦点与可操作图形 ≥ 3 比 1，按实际合成背景验收。

| 元素 | 基准 |
| --- | --- |
| 字体 | 20 px 页标题、16 px 分区标题、14 px 正文与控件、12 px 元数据。保留系统字体发现与语言自动选择。等宽字体用于路径、代码和 TOML |
| 间距 | 4 / 8 / 12 / 16 / 20 / 24。工具间距 8，内容区 20，区块间距 16 |
| 控件 | 输入、选择、按钮高 32，密集行内操作 28。图标点击区域至少 28 × 28，图标 16 |
| 圆角 | 控件 6，面板 8，菜单 8。列表用分隔线和浅选中色组织 |
| 反馈 | 悬停与按下通过表面色响应，焦点立即显示。排序、Tab、数据替换即时。抽屉和折叠可用 120–160 ms，开启减少动态时即时切换 |
| 键盘 | Tab 进入区域，导航组和 Tab 组内方向键移动，Enter / Space 激活。Ctrl / Cmd + K 聚焦当前页搜索。Esc 关闭当前菜单或面板并还原焦点 |
| 破坏性动作 | 确认显示对象名、目标和范围。提交期间防止重复执行。失败留在原位。删除本地数据须明确确认 |

## 落地与验收

1. **窗口与基础组件**。统一 PageHeader、Sidebar、Tab、工具栏和表单行。验证中、英、日三种语言、不同字号与深浅主题。
2. **技能库**。实现范围、索引和部署检查器。验证全局与项目、共享目录、目标冲突、保存和移除。复用 Core 层部署安全检查。
3. **发现与收编**。实现按内容宽度计算的虚拟网格和详情面板。验证缓存、搜索、最后一个不满行、反复切榜与分页重试。收编按勾选与实际结果验收。
4. **技能组合与设置**。确认加入技能库和部署的动词与执行一致。验证 TOML 导入错误、自定义 Agent、折叠分组焦点、连接失败与更新入口。

NSH 实现使用共享侧栏和官方 Tabs、Button、Input、Select、Dialog，长列表使用虚拟化的 List。给长文本留可缩空间，长列表滚动视口独立于内边距，界面文案进入三语资源。实施后在 960 × 600、1240 × 780、1440 × 900 检查布局。 [NSH 设计指南](https://github.com/longbridge/nsh/blob/v0.6.1/website/zh-CN/docs/design-guides.md) · [NSH 列表指南](https://github.com/longbridge/nsh/blob/v0.6.1/website/zh-CN/docs/lists.md)
